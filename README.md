# LankaTransit

LankaTransit is a real-time bus tracking and passenger information
system designed for Sri Lankan Metro Bus services.

## Technologies

- Frontend: React
- Backend: Node.js + Express
- Database: MongoDB
- DevOps: Git, GitHub, Docker, CI/CD

## Project Goal

The system will allow passengers to:

- Track buses
- View bus routes
- Estimate bus arrival times
- Receive service alerts

The project will also demonstrate DevOps practices such as
automated testing, CI/CD, containerization, deployment,
monitoring, and security.
